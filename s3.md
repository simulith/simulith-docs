# S3 — Simulith local runtime

Amazon S3 REST subset for local development with AWS CLI and SDKs (`--endpoint-url`).

> **Status:** buckets, object CRUD, ListObjectsV2, **ListObjectVersions** (current object version IDs), bucket versioning/SSE-S3/lifecycle/tags, `simulith verify s3`, and Terraform green paths including **`terraform-state-min` destroy**.

---

## Available operations

| Operation | Status | Notes |
| --- | --- | --- |
| ListBuckets | Available | All buckets in local store |
| CreateBucket | Available | Idempotent when bucket already exists |
| DeleteBucket | Available | Empty bucket only (`BucketNotEmpty` otherwise) |
| PutObject | Available | Single-part upload; Content-Type from request header |
| CreateMultipartUpload | Available | POST `?uploads` on object key |
| UploadPart | Available | PUT with `partNumber` + `uploadId`; part ETag = MD5 of part |
| CompleteMultipartUpload | Available | POST with `uploadId` + XML parts list; multipart ETag `{md5}-{n}` |
| AbortMultipartUpload | Available | DELETE with `uploadId` |
| GetBucketNotificationConfiguration | Available | GET `?notification`; empty config when unset |
| PutBucketNotificationConfiguration | Available | PUT `?notification`; Lambda targets only |
| GetObject | Available | Returns body with Content-Type, Content-Length, ETag |
| HeadObject | Available | Metadata only (existence check) |
| DeleteObject | Available | Idempotent (204 even when key was missing); `?versionId=` deletes the current object when it matches |
| CopyObject | Available | Same-bucket and cross-bucket; `x-amz-copy-source` header |
| DeleteObjects | Available | Batch delete up to 1000 keys (`POST ?delete`); honors `<VersionId>` for the current object |
| ListObjectsV2 | Available | `prefix`, `max-keys`, `continuation-token` (basic pagination) |
| ListObjectVersions | Available | Current objects only (last-write-wins; no noncurrent history) |
| HeadBucket | Available | Returns 200 if bucket exists, 404 otherwise |
| GetBucketLocation | Available | Returns region (empty = `us-east-1`) |
| GetBucketVersioning | Available | Empty when unset; `Enabled` / `Suspended` after Put |
| PutBucketVersioning | Available | Persists status; Enabled assigns per-object version IDs (current only) |
| DeleteObject | Available | Idempotent (204 even when key was missing); `?versionId=` deletes the current object when it matches |
| DeleteObjects | Available | Batch delete up to 1000 keys (`POST ?delete`); honors `<VersionId>` for the current object |
| GetBucketEncryption | Available | 404 when unset; SSE-S3 (`AES256`) after Put |
| PutBucketEncryption | Available | SSE-S3 only (`FW-S3-023` for KMS) |
| DeleteBucketEncryption | Available | Clears stored SSE-S3 config (204) |
| GetBucketLifecycleConfiguration | Available | 404 when unset; `x-amz-transition-default-minimum-object-size` header (Terraform v5 waiter) |
| PutBucketLifecycleConfiguration | Available | Persists rules; does not expire objects |
| DeleteBucketLifecycle | Available | Clears stored rules (204) |
| GetBucketTagging | Available | 404 when unset |
| PutBucketTagging | Available | Persists bucket tags |
| GetBucketACL | Available | Returns owner `FULL_CONTROL` stub |
| GetBucketAccelerate / RequestPayment | Available | Returns empty stubs for Terraform provider read cycle |
| simulith verify s3 | Available | `simulith verify s3 --skip-aws` (8 scenarios); parity with AWS creds |
| Terraform `aws_s3_bucket` + `aws_s3_object` | Available | `s3_use_path_style = true` required; `force_destroy` supported |
| Terraform `terraform-state-min` | Available | Versioned bucket + DDB lock for `backend "s3"` |
| Terraform `multi-root-min` | Available | Downstream apply + overlay-free `terraform_remote_state` |

## Quick test (AWS CLI)

With Simulith running on `:4566`:

```bash
aws s3api create-bucket --bucket my-app-data --endpoint-url http://127.0.0.1:4566
aws s3api put-object --bucket my-app-data --key config/app.json --body ./app.json --content-type application/json --endpoint-url http://127.0.0.1:4566
aws s3api list-objects-v2 --bucket my-app-data --prefix config/ --endpoint-url http://127.0.0.1:4566
aws s3api get-object --bucket my-app-data --key config/app.json /tmp/out.json --endpoint-url http://127.0.0.1:4566
aws s3api head-object --bucket my-app-data --key config/app.json --endpoint-url http://127.0.0.1:4566
aws s3api delete-object --bucket my-app-data --key config/app.json --endpoint-url http://127.0.0.1:4566
aws s3api copy-object --bucket my-app-data --key config/copy.json --copy-source my-app-data/config/app.json --endpoint-url http://127.0.0.1:4566
aws s3api delete-objects --bucket my-app-data --delete file://delete-keys.json --endpoint-url http://127.0.0.1:4566

# Multipart (large files)
UPLOAD_ID=$(aws s3api create-multipart-upload --bucket my-app-data --key big.bin --endpoint-url http://127.0.0.1:4566 --query UploadId --output text)
ETAG1=$(aws s3api upload-part --bucket my-app-data --key big.bin --part-number 1 --body part1.bin --upload-id "$UPLOAD_ID" --endpoint-url http://127.0.0.1:4566 --query ETag --output text)
aws s3api complete-multipart-upload --bucket my-app-data --key big.bin --upload-id "$UPLOAD_ID" --multipart-upload "Parts=[{PartNumber=1,ETag=$ETAG1}]" --endpoint-url http://127.0.0.1:4566

aws s3api delete-bucket --bucket my-app-data --endpoint-url http://127.0.0.1:4566
```

Expected: create/put/list/get/head return HTTP 200; delete-object and delete-bucket return HTTP 204.

## Storage layout

| Layer | Location |
| --- | --- |
| Bucket metadata | SQLite table `s3_buckets` |
| Object metadata | SQLite table `s3_objects` (Content-Type, ETag, size) |
| Object files | `{state-dir}/s3/{bucket}/{key}` |

Default state path: `./.simulith/state.db` → objects under `./.simulith/s3/`.

Object keys may include `/` (prefix paths). Metadata and files survive runtime restart.

---

## Limits (bucket lifecycle + objects)

- REST API only (not AWS JSON `POST /`)
- Path-style and virtual-hosted bucket URLs on the runtime port — **bucket create/delete and bucket config sub-resources** (policy, versioning, public access block, etc.) work in both styles; object CRUD remains path-style / virtual-host key paths as before
- Bucket names: 3–63 chars, lowercase DNS-style (see AWS S3 naming subset)
- Multipart upload supported (`CreateMultipartUpload`, `UploadPart`, `CompleteMultipartUpload`, `AbortMultipartUpload`); parts stored under `{state-dir}/s3/.multipart/` until complete or abort
- Bucket notifications: `PutBucketNotificationConfiguration` / `GetBucketNotificationConfiguration` (Lambda ARN + events + prefix/suffix filter); **ObjectCreated dispatch** to Lambda on PutObject and CompleteMultipartUpload (async)
- ListObjectsV2: max 1000 keys per page; opaque `continuation-token`
- ListObjectVersions: current objects only; overwrite replaces the version ID (no noncurrent history or delete markers)
- ETag is MD5 hex of object bytes (quoted in response headers)
- DeleteBucket rejects non-empty prefixes (objects under the bucket)
- SigV4 validation optional (same as other services — `auth.validate_signatures`)

## Verify S3

Run curated S3 scenarios against Simulith (smoke) or compare against real AWS (parity):

```bash
# smoke — no AWS credentials needed
simulith verify s3 --skip-aws --endpoint http://127.0.0.1:4566

# parity — requires AWS credentials
simulith verify s3 --region us-east-1 --endpoint http://127.0.0.1:4566
```

Scenarios: `create-list-delete-bucket`, `put-get-object`, `head-object`, `delete-object`, `list-objects-v2-prefix`, `object-round-trip`, `bucket-state-config`, `list-object-versions`.

Save a JSON report: `simulith verify s3 --skip-aws --save-last` (writes `.simulith/verify-last.json`).

## Terraform green path

`aws_s3_bucket` + `aws_s3_object` apply and destroy work on Simulith. Required provider setting:

```hcl
provider "aws" {
  ...
  s3_use_path_style = true   # required for Simulith path-style routing

  endpoints {
    s3 = "http://127.0.0.1:4566"  # or :9080/runtime via Console proxy
  }
}
```

Runnable example: [`examples/terraform/s3/`](examples/terraform/s3/) — bucket + 2 objects.

Remote-state bootstrap: [`examples/terraform/s3/terraform-state-min/`](examples/terraform/s3/terraform-state-min/) — versioned bucket + DynamoDB lock.

Multi-root apply (`backend "s3"` + overlay-free `terraform_remote_state`): [`examples/terraform/s3/multi-root-min/`](examples/terraform/s3/multi-root-min/). Point `AWS_ENDPOINT_URL` at a **hostname** (`localhost` or `127.0.0.1.sslip.io`), not a raw IP, so virtual-hosted GetObject resolves.

**Object lifecycle CLI:** [`examples/aws-cli/s3/`](examples/aws-cli/s3/) — full put/head/get/list/copy/delete-objects flow.

**S3 → Lambda:** [`examples/aws-cli/s3-lambda/`](examples/aws-cli/s3-lambda/) + Terraform [`examples/terraform/s3-lambda/`](examples/terraform/s3-lambda/) — bucket notification + object-create dispatch.

```bash
cd runtime/examples/terraform/s3
cp terraform.tfvars.native.example terraform.tfvars   # for :4566 native
terraform init && terraform apply
terraform destroy
```
